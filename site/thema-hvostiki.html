🧩 Существительные-хвостики

Длинные немецкие слова — из кусочков. Род задаёт последний кусочек — «хвостик». Знаешь хвостик — знаешь род любого слова.

die Straße → die Hauptstraße, die Bahnhofstraße — всё die.
der Platz → der Marktplatz, der Spielplatz — всё der.
das Haus → das Rathaus, das Kaufhaus — всё das.
Три героя — три рода
der · Отто
Хвостики: -platz · -plan · -schein · -weg · -hof · -raum · -lauf · -kauf. Песенка + слова + перевод.
 die · Грета
Хвостики: -bahn · -karte · -zeit · -straße · -tür · -schrift · -kasse · -stelle. Песенка + слова + перевод.
 das · Тео
Хвостики: -haus · -zimmer · -zeug · -buch · -mittel. Песенка + слова + перевод.
Тренажёр
🎯 Определи род по хвостику
Слова всех трёх героев вперемешку — der / die / das по хвостику, с озвучкой и правилом.
