# 15. Карта распределения «урок → тема» (весь А1, без дыр и задвоений)

> Зачем: правило **«каждое слово учебника → ровно ОДНА тема»** (docs/11 §B1). Этот файл — сквозная карта: какой урок Momente A1 в какую тему идёт, чтобы при сборке новых тем ничего не выпало и не задвоилось. Темы — СТРОГО по порядку уроков (docs/11 Шаг A). Слова по урокам с родом — в [10-text-regeln-portable.md](10-text-regeln-portable.md) §7.

## Кросс-перемещения (НЕ по номеру урока, а по смыслу) — единственные исключения
Эти слова открываются на одном уроке, но по СМЫСЛУ живут в другой теме:
- **Контактные/анкетные поля → Тема 1 (Знакомство/анкета)**, хотя лексически L4/L6: die **Adresse, Straße, Hausnummer, Postleitzahl, Stadt, Telefonnummer, Nummer, E-Mail, Visitenkarte** (это «о себе»). В Теме 2 (Быт) их НЕ берём; в Теме 3 (Офис) die E-Mail/Visitenkarte НЕ берём.
- **Сущ. L11 (хобби/медиа) → Тема 4 (Досуг):** der Sport/Handball/Basketball/Film/Urlaub…, die Zeitung/Mode/Boutique/Blume/Serie…, das T-Shirt/Geschenk. Грамматика L11 (Perfekt с haben) → раздел «Глаголы».
- **Сущ. L19 (быт-хозяйство) → Тема 9 (Дом и кухня):** der Müll/Abfall/Haushalt/Boden/Sack, die Spülmaschine/Tüte/Luft/Notiz, das Geschirr/Lied/Spiel. Грамматика L19 (Imperativ du) → «Глаголы».
- **Глаголы любого урока** тренируются и внутри своей темы, но их методика/формы (отделяемые→Otto, неотделяемые→Грета, -ieren→Тео + лестница) — в разделе «Глаголы» ([12](12-verben-methodik.md)).

## Признаки-категории по роду (docs/11 §B2 — для КАЖДОЙ темы)
У слова-категории есть род → признак достаётся «своему» герою, у других — фоном:
- **der Preis / der Euro / der Cent** (цена) → **Otto**. die-герой (Грета) про деньги НЕ говорит.
- **die Farbe** (цвет) → **Грета** (уклон — всё яркое).
- **das Material / das Holz/Metall/Glas/Plastik** (материал) → **Тео**.
- В новой теме: выписать её категории → посмотреть артикль → раздать так же.

## Как пользоваться при сборке темы
1. Взять строку темы → её уроки.
2. Открыть полный **Lernwortschatz** этих уроков (Arbeitsbuch) → выписать ВСЕ существительные, разложить der/die/das (§7).
3. Вычесть кросс-перемещения (что уходит в другую тему) и добавить пришедшие сюда (из списка выше).
4. Сверить: каждое слово уроков попало ровно в одну тему; ничего не выпало (docs/11 §B1).
