# 18 — Блок «Отделяемые глаголы»: полный принцип создания (эталон)

> **Что это.** Полная фиксация того, КАК собран блок `site/thema-trennbar.html` (семья Otto): что хотел пользователь, как написан текст, какие были правки, какие упражнения, в каком порядке, какая глубина и в чём суть каждого. **Это эталон для следующих глагольных блоков** (неотделяемые → Грета, -ieren → Тео).
> Читать вместе с [12-verben-methodik.md](12-verben-methodik.md) (методика «семья=персонаж») и [03-error-log.md](03-error-log.md).
> Движок данных — `tools/gen_trennbar.py` (**источник истины по формам**).

---

## 1. Суть и зачем (что именно хочет пользователь)
- **Проблема:** отделяемый глагол трудно узнать — приставка улетает в конец (*steht … **auf***) или прячется в Perfekt (*auf**ge**standen*). Глазами выучить мало — **нужно ухо**.
- **Цель блока:** узнавать глагол под любой маской (лицо, время, отделённая приставка) и **производить** формы самому.
- **Семья = персонаж:** отделяемые — семья **Otto** (der). Озвучка — **только голос Отто**.
- **Глубина:** не «показать список», а провести каждый глагол через узнавание → формы → производство → слух → прошедшее. Все ~56 глаголов A1 + A2(L1–L3), сверенные по учебнику (`data/verben-trennbar-a1-a2L3.md`).

## 2. Устройство страницы
**5 вкладок = 5 частей** (по ~11 глаголов). 56 глаголов одной стеной — перебор; часть = рабочая порция.
Внутри каждой части — строгий порядок:

**Шаг 1 — изучаем:**
1. 🔤 **Глаголы части + прошедшее** (список, 🔊 инфинитив + ⏪ Perfekt, кнопка «скрыть переводы»)
2. 📜 **Текст части** (история, глаголы кликабельны, 🔊)
3. 🖼 **Картинка части** (кружки-хотспоты)

**Шаг 2 — 12 упражнений** (см. §5).

> Порядок Шага 1 — требование пользователя: **сначала слова, потом текст, потом картинка**. (Менялся: сначала текст был первым, потом картинку двигали вперёд — итог зафиксирован здесь.)

## 3. Текст: как пишется (и какие были правки)
**Правила (кроме общих из [17-text-anleitung.md](17-text-anleitung.md)):**
- **Связная ИСТОРИЯ с причинно-следственной связью, а не набор предложений** под глаголы. Сюжет: праздник в саду → звонит сыну → внук прилетает → готовят → смотрят футбол → вечер, дневник.
- **Präsens** — чтобы было ВИДНО, как приставка отлетает.
- **Только пройденная лексика** (Momente A1 + A2 L1–L3). Не выдумывать слов.
- **Канон Отто соблюдать** (`data/story/otto-bible.md`): нелюдимый шотландец-садовник, килт, сын и внук в Шотландии, секретное приложение.
- **Разметка:** глагол — `VB('форма','инфинитив — перевод')` (клик → инфинитив+перевод), приставка — `P('auf')` (синим).
- **ВСЕ глаголы части обязаны быть в тексте** и выделены — проверять поимённо.
- Перевод глагола в тексте и в списке — **один и тот же** (не «звонить» тут и «позвонить» там).

**Правки, которые пришлось внести (не повторять):**
| Было (ошибка) | Стало |
|---|---|
| Набор несвязанных предложений ради глаголов | Связная история причина→следствие |
| Отто идёт в клуб (Verein) | Убрано — он нелюдимый; мечтает о Шотландии |
| Лексика не из учебника (Ausflug, Keller, Bühne, скворечник…) | Заменена на пройденную |
| В анкете «указывают на ошибки» | «Не хватает данных» → Postleitzahl |
| Перевод глагола в тексте ≠ в списке (7 шт.) | Согласованы |
| `abholen` не выделен в тексте | Выделен |

## 4. Картинка части
- 5 иллюстраций пользователя → `site/img/trenn-part-N.png`.
- **Кружки-хотспоты** (`.spot`, номер) на действиях Отто; клик → показывает **ТОЛЬКО немецкий глагол** (без перевода!) и **озвучивает** его.
- Координаты — в `SPOTS[часть] = [{x,y,de,ru}]` (проценты).

## 5. Двенадцать упражнений — порядок и суть
Порядок — требование пользователя (от узнавания к производству, слух перед прошедшим):

| № | Упражнение | Суть / глубина |
|---|---|---|
| 1 | 🃏 Карточки | RU → вспомни глагол; переворот: инфинитив + Perfekt + 🔊 |
| 2 | 🔗 Соотнеси глагол ↔ перевод | Пассивное узнавание, цветные связи |
| 3 | 🧩 **Раздели: лёгкие ↔ меняют корень** | Осознать поведение ДО спряжения. Ниже — **памятка** (§6) |
| 4 | 🔤 Спряжение: посмотри → впиши → услышь | **СЛУЧАЙНОЕ лицо**, нужная форма **скрыта** (▢▢▢), «🎲 другое местоимение», 🔊 голосом Отто |
| 5 | 🇷🇺→🇩🇪 Выбери немецкий глагол | Значение → форма; обманки — реальные глаголы части |
| 6 | ✍️ Вставь глагол (Präsens) | **2 поля: личная форма + приставка**. ВСЕ глаголы части, **разные лица/подлежащие**, 🔊 предложения |
| 7 | 🎧 Выцепи глагол *(полегче)* | Слушаешь → выбираешь инфинитив из 3 похожих |
| 8 | 🎧 Услышь и переведи *(потруднее)* | Слушаешь (текст скрыт) → **вписываешь** глагол → «Показать» |
| 9 | 🧩 **Раздели по Perfekt: -t ↔ -en** | Осознать причастие ДО его производства. Ниже — **памятка** |
| 10 | ⏪ **Вставь глагол в Perfekt** | **2 поля: hat/ist/habe/bin + причастие**. 🔊 |
| 11 | ✍️ Переведи RU→DE | **Чередует** настоящее и Perfekt (пометка у каждого) |
| 12 | 🏁 Аудирование части | **6 вопросов**, ответ = глагол, пишется рукой |

**Принципы, которые тут зашиты:**
- **Раздели-на-группы идёт ПЕРЕД производством** (и для Präsens, и для Perfekt) — сначала понять поведение, потом писать.
- **Слух (7–8) идёт ДО прошедшего (9–10).**
- **Прошедшее обязательно есть** — упражнение «вставь Perfekt» терялось при пересборке, это ошибка (дневник 2026-07-09).
- Упражнения **не под копирку**: разные лица, подлежащие, контекст из мира Отто.
- **Тест-аудирование:** вопрос **НЕ содержит целевой глагол** (глагол — только в ответе), без вариантов и без перевода.

## 6. Памятка (`.panel.memo`) — отдельный жанр
- Это **справка, а не упражнение** → **отдельный блок ДРУГОГО цвета** (фиолетовый `#6d28d9`), **ПОД** упражнением, **не внутри**.
- Показывает **ВСЕ глаголы части** (не выборку!), в **два столбца** (grid auto-fit → на телефоне один).
- Präsens-памятка: `ich fahre, du fährst, er fährt` + 🔊. Perfekt-памятка: `инфинитив → причастие` + 🔊.

## 7. Озвучка — жёсткие правила
- **Только голос Отто**: `playWord(...)` → mp3 `site/audio/word/<slug>.mp3` (edge-tts **de-DE-KillianNeural**, rate `-8%`, pitch `-2Hz`).
- **НИКОГДА `speak()`** (браузерный робот) — это был реальный баг в спряжении.
- slug: lowercase, ä→ae/ö→oe/ü→ue/ß→ss, `[^a-z0-9]+`→`-`. JS и Python обязаны слугировать одинаково.
- Озвучено всё: инфинитивы, причастия, **все 6 форм каждого глагола** («er steht auf»), предложения Präsens и Perfekt. Всего ~560 фраз.

## 8. Движок — `tools/gen_trennbar.py` (ГЛАВНОЕ)
- **Формы спряжения НЕ писать руками.** Реальные ошибки от ручного набора: `findst/findt` (→ findest/findet), `bereitst/bereitt`, `bietst/biett`, `kreuzst`, `weisst`, `ladt`, `arbeitt`, `schaltt`.
- Правила движка: основа на **-d/-t** → +e (findest/findet); на **-s/-ß/-z/-x** → du = основа+t (kreuzt/weist); **сильные** — таблицей (haben, nehmen, geben, sehen, fahren, waschen, schlagen, fangen, laden).
- Perfekt-упражнение **генерируется автоматически** из Präsens-предложения + причастия: вспомогательный по лицу (habe/hast/hat… / bin/bist/ist…), причастие в конец. Ничего не сочиняем руками.
- Движок **идемпотентен**: повторный запуск не меняет HTML и не перегенерирует аудио.
- ⚠️ **Скрипты держать в `tools/`, НЕ в scratchpad** — временную папку стирает, движок терялся (2026-07-16).

## 9. Технические грабли (проверено на себе)
- **Не класть в HTML-атрибут строки с кавычками** — рвёт атрибут, кнопка мертва.
- **Не ссылаться в `onclick` на переменную-`const`** (напр. `M`): глобальные `const` не лежат на `window`, обработчик падает и **звук молчит**. Только вызов по индексу: `onclick="playDemo(3)"`, а переменные читать внутри функции.
- Данные — в JS, в атрибут — **только индекс**.
- После правки UI — проверять, что ничего не перекрыто/не обрезано, **и на телефоне**.
- Ссылку после деплоя давать с анти-кэшем (`?nocache=…`).
