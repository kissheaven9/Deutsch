## 2. Копирование шаблона — что МЕНЯТЬ в каждой копии
`cp site/thema-02-der.html site/thema-0N-der.html` (и т.д.), затем в копии поправить:
- `<title>` и заголовок `<h1>` (герой/тема);
- **хлебную крошку** `.crumb` в `<header>`: ссылку на `thema-0N.html` и текст «Тема N: <название>»;
- **футер** `.fnav`: ссылку «📚 Тема N» и `dictionary.html?thema=0N`;
- данные-массивы в `<script>` страницы (слова/текст/упражнения — см. §6) под лексику темы;
- `src` картинок (`img/…`);
- бамп анти-кэша `?v=N` у css/js.

> ⚠️ **ЧАСТЫЙ БАГ (копипаста):** забывают поменять крошку/футер — остаётся «Тема 2: Быт». Реальный пример сейчас: `thema-03-der.html:86` крошка «Тема 2: Быт» и футер «📚 Тема 2» + `dictionary.html?thema=02` (должно быть своей темы). Всегда проверять крошку И футер на каждой из 3 страниц героев.

## 3. `js/woerter.js` — структура объекта темы (добавить в `WOERTER.themes[]`)
```js
{
  id:"0N", title:"Название", lessons:"L…",
  nouns:{
    der:[ ["Wort","перевод"], … ],   // 3-й элемент опц.: метка-подгруппа ["Master","магистр","Fokus Beruf"]
    die:[ … ], das:[ … ]
  },
  pluralOnly:[ ["die Eltern","родители"], … ],
  verbs:[
    // [инфинитив, перевод, "reg"|"irr", [6 форм], "Perfekt"]
    ["wohnen","жить","reg",["wohne","wohnst","wohnt","wohnen","wohnt","wohnen"],"hat gewohnt"],
    // отделяемые — с многоточием: ["…","…","reg",["lebe … zusammen", …],"hat zusammengelebt"]
  ],
  other:{ "Прилагательные / состояния":[["alt","старый"], …], "Фразы":[ … ] }
}
```
- Порядок форм глагола: **ich · du · er/sie/es · wir · ihr · sie/Sie** (`PRO` вверху файла).
- **Рода СВЕРЯТЬ** по Lernwortschatz (Arbeitsbuch). Pl. не выдумывать (нет — ставить `—`).
- Словарь по теме: `dictionary.html?thema=0N`; общий — без параметра (накопительно).

## 4. Озвучка — `tools/gen_audio.py` (edge-tts, бесплатно)
**Роли-голоса (`VOICE`):** `male`=Otto (Killian) · `female`=Грета (Katja) · `child`=дети (Seraphina) · `childgirl`=Lina/девочка (Amala выше) · `carla`=соседка (Amala) · `seller`=продавец (Amala).
1. **Сцены героев** — добавить в список `SCENES`: `('scene-XXN','role','thema-0N-XX.html')` (берётся текст из элемента `id="deText"`). Напр. `('scene-der3','male','thema-03-der.html')`.
2. **Диалоги** парсятся автоматически по классу говорящего: `.sp.der`→male, `.die`→female, `.das`→child, `.lina`→childgirl, `.carla`→carla. → В HTML диалога красить реплику ПРАВИЛЬНЫМ классом, иначе голос будет не тот.
3. **Слова** озвучиваются голосом рода. Слова сцен, которых НЕТ в словаре, добавить в список `EXTRA`, иначе будет робот/пропуск.
4. **Запуск:** `python3 tools/gen_audio.py` (из корня репо; `pip install edge-tts`). Готовые файлы пропускаются; новые → `site/audio/`.
5. На страницах озвучка уже подключена в `app.js` (`playWord`/`playSeq`: сначала пробует mp3 `audio/word/<slug>.mp3` или `audio/<id>.mp3`, при ошибке — fallback браузерный TTS). **Проверить, что mp3 реально создан** (иначе слышно робота — это знак, что слово не попало в генерацию).

## 5. Навигация — `js/chrome.js`
В массиве `THEMES` включить тему: дать `href` и `on:true`:
```js
{n:'3. Офис / работа', href:'thema-03.html', on:true},
```
Шапка («Темы ▾») и футер строятся из `THEMES` автоматически. На `index.html` — снять у карточки темы `class="disabled"`, дать `href="thema-0N.html"`, бейдж с уроками.

## 6. Упражнения — где в коде и как развести на 3 группы
- Упражнения встроены в каждую страницу: данные-массивы в `<script>` страницы (`MATCH`, `SORT`, `WRITE`, глаголы) + общие функции в `app.js` (проверка через нормализацию строки).
- **Разнести на 3 непересекающиеся группы** = задать РАЗНЫЕ наборы слов в массивах текста 1 / 2 / 3 (match/sort/write/verbs). В «распредели по родам» (`SORT`) в каждой группе — **все три рода**. Глаголов мало (≈7) → с наименьшим повтором. (Правило — [11 §Правила упражнений](11-tema-bauen.md).)
- Страницы «распредели по родам» по 14 слов + точки-индикаторы страниц — образец в `dialog.html` (функции `renderSort`/`sortNext`/`renderSortDots`).

## 7. Анти-кэш и деплой
- Бамп `?v=N` у css/js на изменённых страницах; во всех html — `<meta http-equiv="Cache-Control" content="no-cache">`. Изменённую картинку переименовывать (имя+буква).
- Деплой из корня репозитория:
  ```
  git push origin main
  git subtree push --prefix=site origin gh-pages
  ```
  Сайт: https://kissheaven9.github.io/Deutsch/ . НЕ публиковать `materials/`.

## 8. Проверка перед «готово» (чек-лист)
- [ ] Открыть все страницы темы (десктоп **и** телефон): ничего не перекрыто/не обрезано, всё помещается.
- [ ] Озвучка живая (не робот) — на словах, тексте героя, репликах диалога.
- [ ] Крошки и футер на 3 страницах героев указывают на СВОЮ тему (не «Тема 2» из копии).
- [ ] `dictionary.html?thema=0N` показывает слова темы; рода верные.
- [ ] Тема доступна с главной (`index.html`) и из шапки (`chrome.js on:true`).
- [ ] Упражнения: 3 текста тренируют разные слова; «распредели по родам» — все рода.
- [ ] `curl`/`grep` живого сайта: новое реально отдаётся (не кэш).

## Что делает пользователь (не ассистент)
Утверждает русские тексты (сцен и диалогов) ДО перевода; присылает картинки (ассистент даёт промпт — §6 в [10-text-regeln-portable.md](10-text-regeln-portable.md)); точечные правки (позиции плашек/точек, голоса, сюжет). Код/файлы/структура — ассистент сам, без вопросов.
