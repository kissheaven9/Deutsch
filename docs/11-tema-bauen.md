# 11. Как собирать ТЕМУ целиком (рецепт + что нравится пользователю)

> Цель: по этому файлу собрать новую тему **самостоятельно и полностью**, как мы сделали Темы 1–2. Читать перед стартом темы. Это то, что пользователь от меня ждёт.

## Что значит «тема готова» (чек-лист результата)
Пользователь открывает тему — и там есть ВСЁ, «как мы любим»:
- [ ] **Хаб темы** `thema-0N.html` — выбор рода (der/die/das) с фото героя и словами; навигация между темами (предыдущая слева, будущие «скоро»); внизу — глаголы, «другое», тексты, словарь.
- [ ] **3 страницы героев** `thema-0N-der/die/das.html` (Otto / Грета / Тео-Lina): картинка с серыми плашками-словами, слова сцены (озвучка + скрыть перевод), текст (DE + RU по кнопке + озвучка), вопросы, **аудирование**, упражнения (карточки, соотнеси, напиши с артиклем, вставь в текст).
- [ ] **Глаголы темы** `verben-thema-0N.html` — список ✅/⚠️ с формами и Perfekt (справка), текст с акцентом на глаголы темы, упражнения (карточки, соотнеси, напиши перевод).
- [ ] **«Другое»** `andere-thema-0N.html?cat=...` — тренировка по категориям (цвета, оценка/свойства, …): слова с озвучкой и скрытием перевода, текст, карточки, соотнеси, напиши по-немецки.
- [ ] **Тексты темы (диалоги)** `dialog{N или 2…}.html?n=1..3` — 3 смешанных текста (все рода), картинка сверху, серые точки-маркеры на предметах, упражнения.
- [ ] **Словарь** темы наполнен в `js/woerter.js` (тема `0N`) → `dictionary.html?thema=0N` работает, плашка с кнопкой «Скачать PDF».
- [ ] **Всё озвучено живым голосом** (не робот): каждое слово/текст/реплика. Проверить, что нет fallback на браузер.
- [ ] **Навигация** между темами и героями расставлена; в шапке (chrome.js) тема включена.

## КАК ПРИДУМАТЬ ТЕМУ И ТЕКСТЫ (автономный принцип — главное)
> Правила НАПИСАНИЯ текстов — в [10-text-regeln-portable.md](10-text-regeln-portable.md): **§0a (🔑 «характер вбивает слово»: трудное/абстрактное слово = черта героя + повтор 4–5×)** · §1 (только свой род) · §1a (анкета — главный приём) · §2a (сигнатурные вещи + уклон по роду + накопительный образ) · §3 и §3a (уровень и грам.стопы) · §5 (группировка по смыслу) · §7 (слова по урокам) · §7a (образцы). docs/11 — про СБОРКУ темы целиком; ниже — как из уроков родить тему и тексты БЕЗ участия пользователя.

**Шаг A. Сгруппировать уроки в тему ПО СМЫСЛУ (не по номеру урока).** Объединять соседние уроки, пока хватает на цельную запоминающуюся картинку; слова одного урока могут уйти в РАЗНЫЕ темы, одна тема может тянуть несколько уроков. Каркас — §5. Ключевое: «анкета-контакты» (адрес/телефон/e-mail) идёт к ТЕМЕ ЗНАКОМСТВА (L1–L6), а не к «вещам»; у die-героя эта тема большая, у der-героя короче (поля по роду — §1a). Обильную тему — на 2 сцены.

**Шаг B. Выписать ВСЮ лексику темы своего рода + функции уровня.** Из Lernwortschatz уроков темы → все существительные разложить der/die/das. В текст героя — ВСЕ слова ЕГО рода (насыщенность). Анкета (если знакомство): все поля своего рода, про МНОГИХ людей, с повтором (§1a).

**🔑 Шаг B2. КАТЕГОРИЯ-ПРИЗНАК ДОСТАЁТСЯ ПЕРСОНАЖУ ПО ЕЁ РОДУ (общее правило, выводить для КАЖДОЙ темы).** Тема вводит свои категории-признаки; у самого слова-категории есть род — по нему признак и закрепляется за героем. Не фиксированный список, а выводимая логика: выписать категории темы → определить род каждой → раздать.
- **Пример (Тема 2):** **der Preis** (цена) → Отто · **die Farbe** (цвет) → Грета · **das Material** (материал) → Тео. Поэтому про цену говорит Отто, про цвета — Грета, про материал — Тео.
- **Как делать в новой теме:** взять её признаки-категории (напр. время/день, оценка, место, количество…), посмотреть артикль слова-категории (der/die/das) и отдать признак соответствующему герою; у других этот признак — лишь фоном, не грузим. Если у героя своей сильной категории в теме нет — он держит тему на своих существительных + сигнатуре.
- **Спираль 30/70:** в тексте ≈30% слов — из прошлых тем (повтор, удержание), ≈70% — новые этой темы (см. docs/02 «Спиральный повтор»). Старое вплетать в сюжет естественно.

**Шаг C. Придумать ЖИВУЮ сцену вокруг персонажа (не список).** Маленькая ситуация с эмоцией/юмором и темпераментом героя, в неё вплести лексику. Опираться на СИГНАТУРНЫЕ вещи героя и его УКЛОН (§2a): **цвет → Грета, материал → Тео, цена/оценка → Otto**. **die-герой (Грета) про деньги/цену НЕ говорит** (der Preis/Euro — мужское). НАКОПИТЕЛЬНЫЙ образ: если предмет/черта уже были — углубить их (камера → «фотографирует», когда придут глаголы; солнце → «лето — любимое», L12). **🔑 ГЛАВНЫЙ ПРИЁМ (§0a «характер вбивает слово»):** трудное/абстрактное слово не называть один раз списком, а сделать чертой героя и повторить **4–5 раз** через сценку (das Glück ×4, das Sonderangebot ×5); смысл — ситуацией, не плоско («теряет das Handy и ищет: Wo ist es?»); уже выученное — сжать.

**Шаг D. Держать УРОВЕНЬ — прогнать КАЖДОЕ слово и конструкцию по §7 + стопам §3a.** Частые ловушки: einen — L6; sein/ihr — L15; предлоги+датив — поздно; Perfekt — L11/12; императив (вкл. «Schau mal!») — L18/19; «нравится/любить» → «… ist schön»/finden schön (gern L7/mögen L9); suchen/brauchen — L6; одежда — L20–22; прилагательные-определения рано — предикативно.

**Шаг E. Сначала РУССКИЙ на утверждение → потом немецкий → один промпт картинки на сцену (§6).** Дальше — сборка по шагам ниже (словарь → озвучка → страницы → упражнения → навигация → проверка).

## Жёсткие правила контента (НЕ нарушать)
1. **Уровень — строго по уроку Momente (не выше).** Грамматика и лексика — те, что введены ДО этого Lektion включительно. На ранних A1 (L1–L5) — **Präsens**, прошедшего нет. Где урок вводит прошедшее (напр. **L20 = Perfekt**) — используем его. **НЕ брать слова/грамматику выше уровня** (пример ошибки: в L20 я вставил sparsam/geizig/erfolgreich — их там нет; убрал). Сверять по Lernwortschatz + упражнениям урока. (см. [[level-only-praesens]])
2. **Разные лица.** Текст разнообразный: ich/du/er/sie/wir/ihr/sie/Sie, не только «я».
3. **Род — строго свой.** Когда учим слова рода (der у Otto, die у Греты, das у Тео), в тексте героя — только его род (гостевые слова другого рода помечать).
4. **Род проверять.** Артикль — ядро; ошибка рода критична. Сверять каждое слово.
5. **Сначала русский на утверждение.** Любой новый текст-история — сперва по-русски пользователю; немецкий — после «ок».
6. **Тексты разнообразные, без повторов** между собой и без воды.
7. **Фишка-слово героя:** Otto → der Preis, Грета → die Farbe, Тео → das Material (в тексте «das ist mein Wort»). Для новой темы — подобрать по смыслу.

## Правила упражнений
- **В разных текстах темы — РАЗНЫЕ слова.** Словарь темы делить на ~3 непересекающиеся группы; текст 1/2/3 тренирует свою. Касается match/sort/write/verbs. В «распредели по родам» в каждой группе — все три рода. Глаголов мало (≈7) → распределять с наименьшим повтором. (см. [[exercises-disjoint-per-text]])
- **«Показать ответ» — только после «Проверить».** Везде.
- **Аудирование:** свой голос у каждого героя; вопрос → впиши → проверь → потом ответ; кнопка «↻ Заново»; пауза/продолжение только своей кнопкой.
- **Слова сцены = слова темы** (набор над текстом сцены = чипы рода в хабе).

## Правила UI/вёрстки
- **Цвет = род:** der синий (#2563EB), die красный (#DC2626), das зелёный (#16A34A). Кнопки-переходы к героям, подписи, плашки, подсветка слов, кнопка «Словарь PDF» — в цвет рода. Фиолетовый (#6D28D9) — «другое»/служебное; жёлтый — глаголы (✅ прав./⚠️ непр.).
- **Подсветка изучаемых слов** в тексте сцены — по роду, слово с его артиклем (mein/ein/der), без надстрочной пометки.
- **Точки-маркеры на картинках диалогов** — серые (род не выдают); при раскрытии слово показывается **с артиклем** и в цвете рода. Позиции — по предметам на фото.
- **Картинки в текстах** — `<img width:100%, height:auto>` (соотношение сторон НЕ менять, не обрезать). Картинки даёт пользователь; если нужна — назвать ей **промпт** (книжная иллюстрация, без текста/букв/цифр).
- **Плашка словаря** — фиолетовая, ВНУТРИ две кнопки: «Открыть словарь» + «Скачать PDF» (`dictionary.html?thema=0N&pdf=1`).
- **Технические надписи** (промпты, «структура темы…», «данные в js/…») пользователю НЕ показывать. «Информация для разработчика» — в сворачиваемом `<details>`.
- После любой правки UI — проверить, что ничего не перекрыто/не обрезано, помещается; **и десктоп, и телефон**.
- **🔑 Согласованность:** меняешь принцип в одном месте — распространяй на ВСЕ страницы.

## Порядок сборки темы (шаги)
1. Определить тему по `docs/09-szenen-inhalt.md` (что включать) и уровень.
2. Собрать словарь темы (der/die/das + глаголы + другое) → **сверить рода** → внести в `js/woerter.js` (тема `0N`).
3. Написать **по-русски**: 3 истории героев + 3 текста-диалога → утвердить у пользователя → перевести на немецкий (Präsens, разные лица, свой род).
4. Сгенерировать озвучку (слова, тексты, реплики, аудирования).
5. Собрать страницы по шаблонам Темы 2 (копировать и менять контент): хаб, 3 героя, глаголы, другое, диалоги.
6. Развести упражнения на 3 непересекающиеся группы.
7. Картинки — запросить у пользователя (дать промпты), вставить с сохранением соотношения сторон.
8. Включить тему в навигацию (chrome.js, главная, соседние темы).
9. Проверить на живом сайте (десктоп+телефон), отчитаться «готово, проверь» с тем, что смотреть.



## Принципы ТЕКСТА (свод правок пользователя — критично)
1. **Богатый и длинный.** Текст героя — 16–20 строк (как у Греты в Теме 2), а не 4 строчки. Цель текста — **задействовать как можно больше лексики темы, желательно ВСЮ** (по Lernwortschatz урока).
2. **Раскрывает характер героя.** Текст не просто перечисляет — он **расширяет образ**: даёт конкретный сюжет и личное. Примеры из L20: Otto «не скупой» — он вкладывал всё в своё приложение, делал его по ночам дома; у приложения конкретная идея (садовое, напоминает поливать цветы, ведь люди забывают); Грета первой попробовала и рассказала всем → первые 10 клиентов. Конкретика + личное = живой текст.
3. **Только лексика ≤ уровня темы** (см. правило 1). Базовые служебные слова из прошлых тем — можно, как «проходные/вспомогательные» для новой.
4. **Делить лексику по героям, не сваливать в один текст.** Если новых слов/глаголов много — разнести на 3 группы (напр. L20: Otto 8 / Грета 7 / Тео 7), и **переписать текст героя строго под его группу**. 22 глагола в одном тексте = перебор, устанет.
5. **Слова героя встречаются часто** (2+ раза каждое), текст плотный.
6. **Сначала русский на утверждение**, потом немецкий (Präsens/нужное время, разные лица).

### ▶ ОБРАЗЕЦ vs АНТИ-ОБРАЗЕЦ (Otto, реальный пример — так видно разницу)
- **✅ ОБРАЗЕЦ (Тема 2 der, финал пользователя):** *«…Fast alles ist aus **Kunststoff** — billig und **praktisch**! Mein Stuhl ist aus Kunststoff, blau. Er **kostet** nur 12 Euro 50 — günstig! Mein Tisch… weiß… 24 Euro 90. Mein Schrank… schwarz… 39 Euro… Der **Preis** ist immer gut! Kunststoff ist **praktisch, billig und gut**. Das bin ich!»* — ВСЕ предметы рода; у каждого материал+цвет+**цена**+оценка; сигнатура Отто (дёшево/практично) вбита повтором (Kunststoff ×5, praktisch ×4, billig/günstig ×5); уклон der = цена/оценка.
- **❌ АНТИ-ОБРАЗЕЦ (Тема 3 der, плоский черновик ассистента):** *«In meiner Freizeit liebe ich den Sport. Ich spiele Fußball im Park. Ich habe einen Verein. Am Sonntag mache ich einen Spaziergang. Manchmal sehe ich einen Film…»* — слова названы **по одному разу**, без глубины, без гипертрофии характера, уклон не задействован.
- **Что делать:** анти-образец ПЕРЕПИСАТЬ по образцу — насытить всей лексикой, каждое слово раскрыть, ключевую черту вбить повтором 4–5× (§0a).

## UX УПРАЖНЕНИЙ (свод правок)
- **Глаголы — жёлтой плашкой, существительные — по роду.** Клик по слову в тексте → перевод прямо в тексте (показываем само слово как оно стоит, **без «hat … глагол» и троеточий**).
- **Отделяемые глаголы: подсвечивать ОБЕ части** (steht … **auf**, habe … **erfunden**) — это один глагол, приставка улетела в конец; обе части кликаются на один перевод.
- **Упражнение «приставка меняет смысл» — ПЕРВЫМ** (основа перед текстом). Для каждой пары: пример без приставки и с приставкой + **смысл приставки** (auf-=начало, ein-=внутрь/запас, be-=на объект/получить, ver-=мимо/изменение, er-=создать/до конца, zurück-=обратно, mit-=вместе). По глаголам героя текущего текста.
- **Словарик текста — только нужные слова** (в теме глаголов — только глаголы, существительные убрать).
- **«Соотнеси»:** клик по немецкому слову — автоозвучка.
- **«Поставь в Perfekt»:** только немецкий инфинитив + 🔊, без русского.
- **Вставка/Lückentext:** делать ОЧЕВИДНОЙ — у каждого пропуска подсказка-инфинитив в скобках (видно, какой глагол), задача — форма; после проверки — кнопка «Послушать».
- **Аудирование/диктант:** простое предложение, слушаешь → пишешь (перевод или само предложение целиком). Простота важнее сложности — цель «услышать глагол».

## Процесс и поведение (свод)
- **Источник — учебник Momente** (Kursbuch+Arbeitsbuch в materials/): открыть нужный Lektion через pypdf, взять РЕАЛЬНУЮ лексику (Lernwortschatz) И упражнения. Не выдумывать. (см. [[textbook-momente-source]])
- **Проверять ДО отчёта** (curl живого + grep). **Ссылку слать с уникальным параметром** `?fresh=<рандом>` — иначе у пользователя кэш.
- **Не игнорировать и не делать частично:** фиксировать ВСЕ пункты сумбурного сообщения; запутался — спросить, а не бросить. (см. [[no-partial-no-ignore]])

## Что пользователь делает сама (её вклад)
- Утверждает русские тексты; присылает картинки (я даю промпты); даёт точечные правки по позициям плашек/точкам, голосам, сюжету. Технические решения (код, файлы, структура) — на мне, без вопросов.
