# Бриф для Клода: генератор упражнений «Персонажи»

Скопируй весь этот текст, вставь в конец свой **текст и список глаголов** (раздел 7) и отдай Клоду. На выходе получишь один готовый HTML-файл с тремя упражнениями в том же стиле, что прототип `greta-verben.html`.

---

## 1. Идея методики (контекст — прочитай, прежде чем делать)

Приложение учит немецкому через **персонажей**. Каждому грамматическому классу соответствует персонаж, который **воплощает** его свойство, — тогда грамматика запоминается не заучиванием, а через образ.

**Существительные (род):**
- **Otto** — мужчина — слова **der**
- **Greta** — женщина — слова **die**
- **Theo и Lina** — дети — слова **das** (средний род)

**Глаголы (класс):**
- **Otto** — **отделяемые** (trennbare). Приставка отрывается и улетает в конец, `ge` в прошедшем прячется в середину: auf**ge**standen.
- **Greta** — **неотделяемые** (untrennbare). Приставка приклеена намертво, `ge` в прошедшем **нет**: verstanden.
- **Theo и Lina** — глаголы на **-ieren**. В прошедшем просто `-t`, без `ge`: studiert.

**Ключевой принцип для глаголов:** сам факт, что глагол отделяемый/неотделяемый, запоминать НЕ надо — он приложен к персонажу (Greta → значит приставка приклеена и `ge` нет, это ясно из группы). **Упражнения заняты только ЗНАЧЕНИЕМ глагола.** У неотделяемых значения абстрактные и образные (постичь, обдумать, решить, обратить внимание) — именно они запоминаются плохо, и вся работа упражнений — привязать это абстрактное значение к яркой картинке и к персонажу.

## 2. Что ты получаешь на входе

В разделе 7 будет:
- **Текст** на немецком (короткая история/диалог), в котором встречаются целевые глаголы в разных формах.
- **Список целевых глаголов** — те, что нужно запомнить из этого текста.

Ты сам определяешь для каждого глагола:
- к какому персонажу он относится (отделяемый → Otto, неотделяемый → Greta, на -ieren → дети);
- дословный разбор приставки + корня;
- образ-сценку;
- перевод;
- есть ли совпадающая русская идиома;
- какие глаголы из набора легко спутать между собой.

И вытаскиваешь из текста реальные предложения с этими глаголами (в их изменённых формах) — они пойдут в упражнение «На слух».

## 3. Что ты делаешь на выходе — три упражнения

Собери **один самодостаточный HTML-файл** (весь CSS и JS внутри, без внешних файлов, без localStorage) с тремя вкладками. Визуальный и кодовый образец — файл `greta-verben.html`, повтори его структуру и стиль.

### Упражнение 1 — «Карточка» (знакомство со значением)
Ритуал из трёх касаний, значение входит через сценку раньше слова:
1. Показывается только **эмодзи-сценка** + звучит инфинитив (кнопка 🔊). Перевода ещё нет.
2. По кнопке — **дословный разбор**: приставка + корень → физическая картинка («be + greifen (хватать) → Greta хватает мысль рукой»).
3. По кнопке — **перевод** как подпись + строка «🇷🇺 Русский думает так же» с идиомой, если совпадение есть.
Кнопка листает все целевые глаголы. Точки-прогресс снизу.

### Упражнение 2 — «Не перепутай» (разведение синонимов)
Главная механика для неотделяемых. Даётся **русское значение**, а два похожих глагола различаются по жесту персонажа. Пример: «обдумать» → überlegen (раскладывает варианты) vs entscheiden (отрезает лишнее). Правильный — подсветить зелёным, неправильный — оранжевым с подсказкой «это другое действие». Составляй пары только из глаголов набора, которые реально ложатся на одно русское слово.

### Упражнение 3 — «На слух» (узнавание в тексте)
Берёшь **настоящие предложения из данного текста** с целевыми глаголами (в изменённых формах — begriffen, versteht, hat … bemerkt). Кнопка «Слушать фразу» произносит предложение (текст скрыт), ученик выбирает значение глагола из вариантов. Это тренирует узнавание глагола, когда форма изменилась. Правильный ответ показывает саму фразу текстом.

## 4. Как придумывать сценки (правила образов)

Абстрактное значение делается запоминаемым тремя приёмами — используй их именно в этом порядке приоритета:

1. **Буквальный образ-мост.** Разбери глагол дословно (приставка + корень) и преврати в смешную физическую сценку. Это не «настоящий смысл», а зацепка: `begreifen` = хватать → «ухватить умом»; `überlegen` = класть поверх → раскладывать/взвешивать; `entscheiden` = разделять прочь → отрезать вариант.
2. **Русская идиома.** Если немецкий образ совпадает с русским выражением — обязательно покажи: begreifen → «ухватить суть», verstehen → «до меня дошло». Такие глаголы самые липкие, ставь их первыми.
3. **Разведение синонимов.** Если несколько глаголов из набора переводятся одним русским словом — дай каждому отдельный, непохожий жест персонажа, чтобы они не слиплись.

Эмодзи-сценка должна быть простой и однозначной (1–2 эмодзи). Персонаж в сценке — всегда «хозяин» класса (у неотделяемых это Greta).

---

## 5. Оформление

- **Цвет персонажа = его род/группа.** Otto (der) — синий, Greta (die) — малиновый/красный, Theo и Lina (das) — зелёный. Весь экран группы выдержан в цвете персонажа.
- **Аватар персонажа** и бейдж группы в шапке (напр. «die · untrennbare Verben»).
- **Напоминание грамматики в шапке**, а не в упражнениях: для Greta — «приставка приклеена, ge нет»; для Otto — «приставка улетает, ge в середине»; для детей — «просто -t».
- В слове **подсвечивай приставку** цветом персонажа (у Greta — приклеенной, без зазора).

## 6. Технические требования

- Один HTML-файл, весь CSS и JS инлайн, ноль внешних зависимостей, **никакого localStorage/sessionStorage**.
- Озвучка — через `window.speechSynthesis`, `lang="de-DE"`, с выбором немецкого голоса (см. функцию `say()` в образце).
- Данные глаголов и упражнений — простыми массивами в начале скрипта (`VERBS`, `QZ`, `EAR`), чтобы их легко было дополнять.
- Мобильная вёрстка, ширина карточки ~460px, крупные тапабельные кнопки, скругления, мягкие тени.
- Плавные раскрытия (reveal) и точки-прогресс, как в образце.
