# Deutsch — система запоминания немецкой лексики (A1 → A2)

Сайт для запоминания немецких слов: род привязан к персонажу (der→Otto, die→Грета, das→Тео/Lina), лексика подаётся через сюжетные тексты-истории, картинки и мультисенсорику (читать / слушать / проговаривать). Глаголы — по методике «семья = персонаж» + лестница из 8 шагов. Лексика **возвращается из темы в тему** (спираль), чтобы не забывалась.

Сейчас — **под себя и на тесте** (пользователь + репетитор). Перспектива — открыть для других.

## Где живёт
- **Живой сайт:** https://kissheaven9.github.io/Deutsch/ (GitHub Pages).
- Сайт **статический** — обычные HTML/CSS/JS, без сервера и сборки.

## Как запустить
- **Локально:** открыть `site/index.html` в браузере. Для корректной работы относительных путей лучше через локальный сервер:
  ```bash
  cd site && python3 -m http.server 8000   # затем открыть http://localhost:8000
  ```
- **Обновить живой сайт (деплой):**
  ```bash
  git push origin main
  git subtree push --prefix=site origin gh-pages
  ```
  Ссылку после деплоя давать с анти-кэшем (`?v=<число>`), при сомнениях — открывать в инкогнито.

## Источник лексики
Курс строится по учебнику **Momente** — **A1** (Kursbuch + Arbeitsbuch) и **A2.1** (Kursbuch + Arbeitsbuch), лежат в `materials/`. **Тема = смысловая группа соседних уроков, СТРОГО по порядку** (Тема 1 = L1–L3 «Знакомство/анкета», Тема 2 = L4–L5 «Быт»; далее по порядку — Офис/работа (L6), Свободное время (L7)…; Тема 20 = Lektion 20 — особая, по глаголам). Распределение «слово → ровно одна тема» — см. [docs/11](docs/11-tema-bauen.md). Берём оттуда **список слов и глаголов по уровню** (Lernwortschatz + упражнения урока); ориентир уровня сверяем с открытым стандартом **Goethe A1 Wortliste**. **Тексты и упражнения пишем свои** (оригинальные истории про Otto/Грету/Тео) — учебник даёт «какие слова на уровне», а не готовый контент.
> `materials/` (учебники) — **локально, НЕ публиковать** (копирайт; в `.gitignore`).

## Статус
В разработке, не «сбор требований».

**A1:** **Тема 1** (L1–L3 Знакомство/семья) и **Тема 2** (L4–L5 Быт) — открыты. **«Свободное время»** (L7–L8) собрана, но пока скрыта: стоит как «Тема 3», а это перескок через непройденный **Офис L6** — после сборки Офиса переслотить в Тему 4. **Тема 20** (L20) — особая, по глаголам (Perfekt/приставки).

**A2:** **Тема 2 «Работа/профессия»** (A2 L2) и **Тема 3 «Переезд/Новый край»** (A2 L3) — открыты.

**Глагольные блоки:** **«Отделяемые глаголы»** (семья Otto, A1 + A2 L1–L3, ~56 глаголов) — 5 частей-вкладок, 12 упражнений в каждой, полная озвучка Отто, тренировка на слух и Perfekt. Эталон и полный принцип сборки — [docs/18](docs/18-block-trennbar-anleitung.md); данные генерирует `tools/gen_trennbar.py`.

У тем: род по персонажам, сцены, словари, упражнения, тренажёры глаголов, озвучка живым голосом (mp3, edge-tts). Методика «семья=персонаж» + лестница шагов, спиральный повтор. Образец полного цикла тем — Темы 1–2.

## Структура репозитория
- `site/` — сам сайт (страницы тем/сцен, `js/`, `css/`, `img/`, `audio/`). Деплоится в ветку `gh-pages`.
- `docs/` — документация и правила (см. карту ниже).
- `data/` — данные: словари тем, story-bible персонажей.
- `materials/` — учебники Momente (**не публиковать**).
- `tools/` — вспомогательные скрипты (генерация аудио, данных).
- `Дизайн/` — дизайн-система и живой кит.
