# Карта: уроки → ТЕМЫ → слова (план сборки всех тем А1, строго по порядку)

> Цель: чтобы темы собирались **по порядку уроков, без пропусков и без потери слов**. Каждое слово учебника попадает ровно в одну тему (по смыслу). Полные списки слов по урокам — в [10-text-regeln-portable.md](../docs/10-text-regeln-portable.md) §7 (der/die/das) и [otto-der-alle-lektionen.md](otto-der-alle-lektionen.md) (der). Правила сборки — [docs/11-tema-bauen.md](../docs/11-tema-bauen.md).
> **Порядок строгий:** не браться за более позднюю тему, пока не доделана более ранняя (docs/11 §Шаг A). Слова — только из уроков темы + спираль из пройденных.

## Особый случай — «Тема 20»
На сайте «Тема 20» = **тренажёр глаголов Lektion 20** (Perfekt, приставки: семья=персонаж). Это часть лексики Темы 11 (L19–L20), но подаётся как отдельный глагольный спецблок (уже собран). Существительные/«другое» L19–L20 — в Тему 11 позже.

## Правила распределения (чтобы ничего не терять)
- **Каждое слово учебника → ровно одна тема** (по смыслу). Один урок может раздать слова в разные темы; одна тема может тянуть из нескольких уроков (но соседних, по порядку).
- **Анкета-контакты (адрес/улица/дом/индекс/телефон/e-mail — женские)** идут к Теме 1 (Знакомство), даже что они из L4–L6: по смыслу это «о себе», и у Греты (die) это её богатая анкета.
- **После сборки темы — сверять её словарь против полного Lernwortschatz её уроков** (Arbeitsbuch); чего нет — добавить. Ни одно слово не должно выпасть.
- Региональные (A/CH) и Fokus-Beruf (Magazin) — факультатив, можно опускать/помечать.
